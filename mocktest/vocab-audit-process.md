# 單字庫稽核流程（比對劍橋詞典）

> 這份文件是寫給**負責稽核單字庫的 AI** 看的操作手冊。目的只有一個：**用劍橋詞典檢查現有 2115 個字的詞性跟中文意思有沒有錯**，把發現的問題整理成一份報告，**不要直接修改任何檔案**。

---

## 0. 背景（為什麼要做這個稽核）

現有單字庫（`vocab-bank.md` / `cycle_mode_mvp.html` 裡的 `defaultWordBank()`）的詞性跟中文意思，**是 AI 憑語言知識生成的，沒有經過任何權威詞典逐字核對過**：

- 有一部分字，原始來源 PDF 只給「英文字 + 一句很粗略的中文翻譯」（完全沒有詞性）；AI 是自己判斷詞性、重寫中文意思。
- 另一部分字，原始來源有給英文詞性跟英文釋義，但中文翻譯一樣是 AI 自己翻的，沒有對照中文詞典。

也就是說，這個單字庫**可能存在**：詞性標錯、中文意思不準確、義項分組不合理（該分開的合併了，或不該分開的拆開了）、甚至極少數是 AI 憑空生出、實際上不存在的用法或片語。這次稽核就是要找出這些問題。

---

## 1. 稽核來源：劍橋詞典（英漢繁體）

指定的比對來源是 **Cambridge Dictionary 英文-中文（繁體）字典**：

```
https://dictionary.cambridge.org/dictionary/english-chinese-traditional/{查詢字}
```

- 查詢字裡有空格的（片語，例如 `account for`、`a leap of faith`），直接用劍橋的搜尋頁面比較保險，會自動處理空格/大小寫並導到正確詞條：
  ```
  https://dictionary.cambridge.org/search/english-chinese-traditional/direct/?q={查詢字，空格可以直接放進去，讓網址自動編碼}
  ```
- 選劍橋詞典的理由：它同時有**英文詞性標示**（可數/不可數名詞、及物/不及物動詞…）跟**繁體中文對照意思**，剛好對應我們單字庫的兩個核心欄位（`pos` 跟 `meaningGroups`），一次查詢可以同時核對兩件事。
- 如果劍橋詞典查不到某個字或片語（尤其是片語類的 `phr.` 條目），這本身就是一個重要發現——代表這個條目可能是 AI 自己拼湊出來、不是真實存在的英文用法，要特別標記出來（見第 4 節）。

---

## 2. 要核對的資料在哪裡

- 單字資料本體：[vocab-bank.md](vocab-bank.md) 裡「完整資料」那個 fenced code block，每個字是一個 JS 物件：

```js
{
  id: "w1", english: "address", createdAt: ..., wrongCount: 0, stats: null,
  posGroups: [
    { pos: "vt", meaningGroups: [ ["處理","應付"], ["向…致辭","發表演說"] ] },
    { pos: "nc", meaningGroups: [ ["地址"] ] }
  ],
  examples: [ ... ]
}
```

- 每個字的資料格式規則（`pos` 縮寫定義、`meaningGroups` 分號/編號規則等）寫在 [vocab-bank-guidelines.md](vocab-bank-guidelines.md)，稽核前請先讀過，這樣才知道「現在這樣寫」代表什麼意思，才能跟劍橋詞典的呈現方式做對應。
- 你**只需要讀** `english`、`posGroups`（含 `pos` 和 `meaningGroups`）這幾個欄位去比對。`id`／`createdAt`／`wrongCount`／`stats`／`examples` 不在這次稽核範圍內（例句品質如果順手發現明顯有問題可以順便記一筆，但不是稽核重點）。

---

## 3. 詞性對照表（我們的縮寫 vs 劍橋的標示）

| 我們的 `pos` | 意思 | 劍橋詞典對應標示 |
|---|---|---|
| `vt` | 及物動詞 | `verb [T]` |
| `vi` | 不及物動詞 | `verb [I]` |
| `nc` | 可數名詞 | `noun [C]` |
| `nu` | 不可數名詞 | `noun [U]` |
| `adj` | 形容詞 | `adjective` |
| `adv` | 副詞 | `adverb` |
| `prep` | 介系詞 | `preposition` |
| `conj` | 連接詞 | `conjunction` |
| `phr.` | 片語/慣用語 | `idiom` 或 `phrasal verb`，劍橋會直接把整個片語當作一個詞條 |

**常見狀況**：劍橋詞典有些動詞標成 `[T, I]`（及物不及物都可以），代表我們的字如果只選了 `vt` 或只選了 `vi` 其中一個，**不算錯**，但可以在報告裡註記「劍橋顯示兩用，我們只收錄了一種，供參考」。

---

## 4. 稽核步驟（每個字怎麼查、怎麼判定）

對單字庫裡**每一個字**（依 `posGroups` 展開，一個字可能有好幾個詞性要分別核對）：

1. 用第 1 節的網址查劍橋詞典英漢繁體字典的詞條。
2. **詞性核對**：我們標的 `pos`，劍橋詞典有沒有對應的詞性？對照第 3 節的表。
3. **意思核對**：我們 `meaningGroups` 裡的中文意思，是不是劍橋詞典底下某個義項的中文翻譯（不用逐字一樣，但核心意思要對得上）？
4. **分組核對**：我們把哪些意思用分號放在同一組（同義詞）、哪些意思拆成不同編號（不同義項），劍橋詞典的義項編號方式是不是也大致這樣分？如果劍橋把我們合併在一起的兩個意思拆成兩個明顯不同的義項，或反過來，都要記錄下來。
5. **缺漏檢查**：劍橋詞典有沒有列出一個**明顯常見、但我們完全沒收錄的義項或詞性**？如果有，記錄下來（是否要新增由使用者決定，稽核階段只負責發現、不負責新增）。
6. 依照第 5 節的四種判定結果，把這個字（或這個字的某個詞性）歸類，寫進報告。

---

## 5. 判定結果（四選一）

| 判定 | 代表意思 |
|---|---|
| ✅ **一致** | 詞性、意思、分組都跟劍橋詞典吻合（或劍橋沒有明確衝突的資訊） |
| ⚠️ **需要修正** | 詞性標錯、意思不準確/翻譯有誤、或義項分組不合理，要具體寫出「現在是什麼、劍橋顯示應該是什麼」 |
| ❓ **劍橋查不到** | 這個字（或這個片語）在劍橋英漢繁體字典裡找不到對應詞條——需要特別留意，可能是拼字錯誤、太冷僻、或是 AI 生成時就不存在的用法 |
| ➕ **有缺漏義項** | 現有條目沒問題，但劍橋詞典有列出一個我們沒收錄、且看起來蠻常見/實用的額外意思或詞性 |

---

## 6. 稽核報告怎麼寫

**不要修改 `vocab-bank.md` 或 `cycle_mode_mvp.html`。** 稽核的產出是一份**新的、獨立的報告檔案**，建議格式如下，存成 `vocab-audit-report.md`，放在同一個 `mocktest/` 資料夾：

```markdown
# 單字庫稽核報告（比對劍橋詞典）

稽核日期：YYYY-MM-DD
稽核範圍：w1 ~ w2115（或註明只做了哪個區間）
稽核來源：劍橋詞典英漢（繁體）

## 摘要
- 總共稽核：N 個字
- ✅ 一致：N 個
- ⚠️ 需要修正：N 個
- ❓ 劍橋查不到：N 個
- ➕ 有缺漏義項：N 個

## ⚠️ 需要修正（依 id 排序）

### w38 admission
- 現有：`(nc) 1. 承認；招認　2. 入場許可；准入`
- 劍橋顯示：義項 1「承認」為 `noun [C or U]`，義項 2「入場許可」劍橋標為 `noun [U]`，我們兩個都標 `nc` 可能有一個要改成 `nu`
- 建議：需要人工確認後再決定要不要改

## ❓ 劍橋查不到

### w2009 xxx
- 查詢網址：...
- 說明：劍橋詞典沒有這個詞條，懷疑是原始 PDF 解析錯誤或 AI 生成時的錯字

## ➕ 有缺漏義項

### w1 address
- 劍橋詞典還有「（正式）稱呼某人」這個用法我們沒收錄，是否要新增請使用者決定
```

每一筆記錄至少要包含：**id、英文字、現有內容、劍橋詞典顯示的內容（附查詢網址方便覆查）、簡短說明**。方便使用者或負責修正的人（不論是人還是另一個 AI）之後能直接根據這份報告動手改，不用重新查一次。

---

## 7. 規模與建議做法

2115 個字如果每個字都真的去查一次劍橋詞典網頁，是很大量的查詢工作。建議：

1. **分批進行**：跟單字庫本身建立時一樣的做法，切成多批（例如每批 100~150 個字），一批一批做，不用一次做完 2115 個才交報告——可以每完成一批就先輸出到同一份報告檔案裡（用 append 的方式累加，不要每次都整份重寫），讓使用者能隨時看到目前進度。
2. **如果沒辦法/不想全部做完**：可以先從**你判斷風險較高的字**開始，例如：
   - 片語類（`phr.`）條目——這類最容易是 AI 生成時「無中生有」的
   - 有多個 `posGroups` 或多個義項編號的字——分組判斷本來就比較主觀，出錯機率較高
   - 比較少見、生活化程度低的單字（不是核心商業字彙的那些）
3. **一律不要邊查邊改**：稽核跟修正是兩個分開的階段。這次任務只負責產出報告，讓使用者看過報告之後，再決定要不要另外開一次「修正」的任務去真的動手改 `vocab-bank.md` / `cycle_mode_mvp.html`。

---

## 8. 絕對禁止事項

- **不要修改 `vocab-bank.md`、`cycle_mode_mvp.html`、`vocab-bank-guidelines.md`，或任何其他專案檔案。** 稽核階段只讀取、不寫入這些檔案。
- 不要因為劍橋詞典查不到就自己編一個意思填進報告裡當作「正確答案」——查不到就照實記錄「查不到」，讓使用者自己判斷。
- 不要跳過任何字自己覺得「應該沒問題」就不查——稽核的價值就在於全部依實際查詢結果判斷，不是憑印象。
